# Photos and video: read before using

These are **placeholders** from the approved mockup. They are fine for building and preview, not yet for launch.

- Source: free stock photos found on Unsplash during the mockup. The photo page links and photographer names were **not recorded**, so before launch either:
  1. find each photo again on Unsplash, download the original and note its page URL and photographer in `CREDITS.md`, or
  2. replace it with our own photos or an operator's photos used with written permission.
- Edits made for the mockup: aircraft registrations were removed from both jet photos; a hotel name was blurred in the Udaipur photo; `shreeji-arrival-composite.jpg` is a **composite** (a couple photo and a helicopter photo put together). Keep it captioned "Illustrative".
- `design/video/` (hero loop and 27 s film) is made from these same photos, so it follows the same rule.
- Every stock or placeholder image on the site carries the caption "Illustrative". Never present one as a Vaanika event.
- Never use a photo that shows an operator's logo, an aircraft registration or a hotel's name.
